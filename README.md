# Programación Web 2026-II
## Proyecto Final — Hormiga Visual

Este repositorio corresponde al **Proyecto Final de Programación Web 2026-II**, desarrollado para la materia de **Programación Web**, correspondiente al **quinto semestre** de la carrera de **Ingeniería en Desarrollo de Software**.

El proyecto consiste en el desarrollo de **Hormiga Visual**, una página web enfocada principalmente en la promoción de **sesiones de fotografía de estilo urbano**, ofreciendo diferentes paquetes y servicios de fotografía.

El proyecto será desarrollado de manera colaborativa por los alumnos **Otilio Gamboa Carrillo** y **Alejandro Manuel Cota Ayala**, utilizando diferentes tecnologías web como **HTML, CSS, JavaScript, servidores y programación del lado del servidor**.

## Descripción del proyecto

**Hormiga Visual** es un proyecto web orientado a la promoción de servicios de fotografía, principalmente enfocados en un estilo **urbano y contemporáneo**.

La página web tendrá como finalidad presentar los servicios de fotografía disponibles, mostrar información sobre las sesiones y ofrecer diferentes **paquetes de fotografía**, buscando crear una experiencia visual atractiva y fácil de utilizar para los visitantes.

## Tecnologías que se utilizarán

1. **HTML** - Para crear la estructura y contenido de las páginas web.
2. **CSS** - Para diseñar y dar estilos a las interfaces.
3. **JavaScript** - Para agregar interactividad y funcionalidad.
4. **Servidores** - Para alojar y gestionar las aplicaciones web.
5. **Programación del lado del servidor** - Para procesar información y realizar operaciones desde el servidor.
